Реализация структур данных на C++

Учебный проект на С++, с ручной реализацией основных структур данных

Цель проекта — самостоятельная реализация основных структур данных с нуля с использованием ручного 
управления памятью, шаблонов, пользовательских итераторов и механизмов обеспечения безопасности исключений. 
В проекте также реализованы балансировка деревьев, хеширование, модульные тесты и сравнение 
производительности собственных контейнеров с аналогами из стандартной библиотеки C++.

Состояние проекта: проект находится в разработке. 
  Реализованы Vector, List, RBTree, хеш-таблица с методом цепочек и
  хеш-таблица с открытой адресацией.

Реализованные структуры данных:
Vector<T>
  Динамический массив с пользовательскими итераторами, поддержкой копирования и перещения, управление
  размером и вместимостью, вставкой и удалением элементов. Для работы с памятью используется std::allocator,
  операция перераспределение памяти предусматривают откат при возникновении исключений

List<T>
  Двусвязный список с пользовательскими итераторами. Реализованы вставка и удаление элементов, изменение
  размера, а также операции splice, remove, unique, reverse и сортировка слиянием.

RBTree<T>
  Красно-чёрное дерево с балансировкой после вставки и удаления элементов. Поддерживает повороты дерева,
  поиск, пользовательские итераторы, проверка корректности структуры дерева.

HashMapChaining<Key, Value>
  Хеш-таблица с разрешением коллизий методом цепочек. Поддерживаются пользовательские функции хеширования 
  и сравнения ключей, вставка, поиск и удаление элементов, итераторы, управление коэффициентом заполнения, 
  а также операции reserve и rehash.

HashMapOpenAddressing<int, int>
  Хеш-таблица с открытой адресацией и линейным пробированием. Для ячеек предусмотрены состояния 
  Empty, Occupied и Deleted. Поддерживаются вставка, обновление, поиск и удаление элементов, повторное       
  использование удалённых ячеек, автоматическое изменение размера таблицы, а также операции reserve и rehash. 
  Коллизии разрешаются без использования связанных списков.


Тестирование

В проекте находится 97(пока что) методов модульного тестирования, распределённых по четырём классам:
- TestsForVector;
- TestsForList;
- TestsForRBTree;
- TestsForHashTableChaining.
- TestsForHashMapOpenAddressing

Тесты проверяют:
- конструкторы;
- копирование и перемещение;
- модифицирующие операции;
- работу итераторов;
- граничные случаи;
- поиск элементов;
- свойства красно-чёрного дерева;
- перераспределение хеш-таблицы;
- другое поведение контейнеров.


Сравнение производительности

Исполняемый проект содержит простой набор тестов производительности, который сравнивает
пользовательские контейнеры с аналогами из STL:

Пользовательская структура      |   Аналог из STL 
Vector<int>                     |   std::vector<int> 
List<int>                       |   std::list<int> 
RBTree<int>                     |   std::set<int> 
HashMapChaining<int, int>       |   std::unordered_map<int, int> 
HashMapOpenAddressing<int, int> |   std::unordered_map<int, int> 

Текущая функция main запускает группы операций для 100 000 элементов.

Эти измерения предназначены для учебного сравнения и не заменяют полноценные библиотеки для бенчмаркинга. 
Результаты зависят от компилятора, уровня оптимизации, оборудования и выбранных операций.
